# Sales Analytics Dashboard Documentation

## Project Title

Sales Analytics Dashboard

## Tool Used

Microsoft Excel

## Dataset

Sales_Data

## Project Overview

This project is about building a simple but useful sales analytics dashboard in Microsoft Excel. The aim of the dashboard is to make the sales data easier to understand by turning the raw data into clear summaries, charts, and key performance indicators.

Instead of looking through many rows of data manually, the dashboard allows users to quickly see important information such as total orders, total revenue, average order value, top revenue product, monthly order trends, payment methods, coupon performance, and order status.

The dashboard was built using Excel features such as pivot tables, pivot charts, slicers, and KPI cards.

## Aim of the Project

The main aim of this project was to create an interactive dashboard that can help users understand sales performance at a glance.

The dashboard was designed to answer questions such as:

- How many orders were made?
- How much revenue was generated?
- What is the average value of each order?
- Which product generated the highest revenue?
- How did orders change across different months?
- Which payment methods were used by customers?
- Which coupon codes contributed to revenue?
- What are the different order statuses?

## Dashboard Features

The dashboard contains four main KPI cards:

### 1. Total Orders

This shows the total number of orders in the dataset.

### 2. Total Revenue

This shows the total amount of money generated from sales.

### 3. Average Order Value

This shows the average revenue made per order.

### 4. Top Revenue Product

This shows the product that generated the highest revenue.

## Charts Created

### 1. Monthly Order Trend

This line chart shows how orders changed from month to month. It helps to identify months with higher or lower order activity.

### 2. Order Count by Status

This chart shows the number of orders based on their status, such as shipped, returned, pending, cancelled, and delivered.

### 3. Payment Method Usage

This doughnut chart shows the payment methods used by customers. It helps to understand how customers prefer to pay for their orders.

### 4. Revenue by Product

This chart compares the revenue generated by each product. It helps to identify the products that contributed most to total revenue.

### 5. Revenue by Coupon Code

This chart shows how much revenue came from each coupon code. It helps to understand the performance of the different coupon categories.

## Slicers Used

To make the dashboard interactive, I added slicers for:

- Month Name
- Product
- Coupon Code

These slicers allow users to filter the dashboard easily. For example, a user can select a specific product or month and the charts will update based on that selection.

## Steps Taken

I followed these steps to complete the project:

1. I imported the sales dataset into Excel.
2. I checked the data to understand the columns and values.
3. I prepared the data for analysis.
4. I created pivot tables to summarize the data.
5. I created pivot charts from the pivot tables.
6. I designed KPI cards for the main business metrics.
7. I added slicers to make the dashboard interactive.
8. I arranged the charts and KPI cards into a clean dashboard layout.
9. I reviewed the dashboard to make sure it was easy to understand.

## Key Findings

From the dashboard, I observed the following:

- Chair generated the highest revenue in the dataset.
- The monthly order trend shows that order activity changed across the year.
- Different order statuses were recorded, including shipped, returned, pending, cancelled, and delivered.
- Customers used different payment methods such as gift card, debit card, online payment, credit card, and cash.
- Coupon codes contributed differently to revenue, meaning some coupon codes performed better than others.

## Conclusion

This project helped me understand how Excel can be used to analyse sales data and present insights in a simple visual format.

The dashboard makes it easier to understand business performance without going through the raw data manually. It also allows users to interact with the data using slicers, which makes the analysis more flexible.

Through this project, I practised important Excel skills such as pivot tables, pivot charts, KPI cards, slicers, dashboard design, and basic sales data analysis.
