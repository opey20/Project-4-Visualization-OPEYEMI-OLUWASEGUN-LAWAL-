# Sales Analytics Dashboard Documentation

## Project Title

Sales Analytics Dashboard

## Tool Used

Microsoft Excel

## Dataset

Sales_Data

## Project Overview

This project focuses on building an interactive Sales Analytics Dashboard in Microsoft Excel. The dashboard was created to transform raw sales data into meaningful visual insights that can support business decision-making.

Rather than reviewing hundreds of rows of sales records manually, users can quickly understand sales performance through key performance indicators (KPIs), charts, and interactive filters.

The dashboard was developed using Excel features such as Pivot Tables, Pivot Charts, KPI Cards, Slicers, and Dashboard Design techniques.

## Aim of the Project

The main aim of this project was to create an interactive dashboard that provides a quick overview of business performance and sales trends.

The dashboard was designed to answer questions such as:

* How many orders were recorded?
* How much revenue was generated?
* What is the average value of an order?
* Which product generated the most revenue?
* Which referral source generated the most customer activity?
* How did order activity change throughout the year?
* What is the distribution of different order statuses?

## Dashboard Features

The dashboard contains six KPI cards:

### 1. Total Revenue

Displays the total revenue generated from all sales transactions.

### 2. Total Orders

Displays the total number of orders recorded in the dataset.

### 3. Average Order Value

Shows the average revenue generated per order.

### 4. Delivered Order Rate

Shows the percentage of orders successfully delivered.

### 5. Top Product

Displays the product that generated the highest revenue.

### 6. Top Referral Source

Displays the referral source with the highest customer activity.

## Charts Created

### 1. Revenue by Product

A horizontal bar chart showing the revenue generated by each product. This helps identify the products contributing the most to total revenue.

### 2. Revenue by Referral Source

A column chart showing customer activity from different referral sources such as Instagram, Email, Google, Facebook, and Referral.

### 3. Monthly Order Trend

A line chart showing how order activity changed across the months of the year. This helps identify peak and low-performing periods.

### 4. Orders by Status

A horizontal bar chart showing the number of orders based on their status, including Delivered, Shipped, Pending, Returned, and Cancelled.

## Slicers Used

To make the dashboard interactive, slicers were added for:

* Month Name
* Product

These slicers allow users to filter the dashboard and view results for specific products or periods.

## Steps Taken

The following steps were followed to complete the project:

1. Imported the sales dataset into Microsoft Excel.
2. Reviewed the dataset to understand the available fields and business metrics.
3. Cleaned and prepared the data for analysis.
4. Created Pivot Tables to summarize key information.
5. Built Pivot Charts from the Pivot Tables.
6. Designed KPI cards for important business metrics.
7. Created an interactive dashboard layout.
8. Added slicers to improve user interaction.
9. Formatted charts and dashboard components for better presentation.
10. Reviewed the dashboard to ensure accuracy and usability.

## Key Insights

The dashboard revealed the following insights:

* Chair generated the highest revenue among all products, contributing approximately €195.6K in sales.
* Instagram was the strongest referral source, generating the highest customer activity with 259 orders.
* June recorded the highest order activity with 147 orders, making it the strongest performing month.
* Cancelled orders recorded the highest count (250), slightly exceeding returned orders (247).
* Total revenue exceeded €1.26 million from 1,200 sales transactions.
* Revenue generation varied across products, indicating that some products performed significantly better than others.

## Recommendations

Based on the findings from the dashboard, the following recommendations can be made:

* Increase marketing efforts on Instagram and Email channels since they generated the highest customer activity.
* Investigate the causes of cancelled and returned orders to improve customer satisfaction and operational efficiency.
* Focus promotional campaigns on high-performing products such as Chair, Printer, and Laptop to maximize revenue.
* Analyse the factors that contributed to the strong performance in June and apply similar strategies during other periods.
* Monitor monthly sales trends regularly to identify seasonal patterns and support better forecasting.
* Continue using dashboards to support data-driven decision-making and performance monitoring.

## Conclusion

This project demonstrates how Microsoft Excel can be used to transform raw sales data into meaningful business insights through data visualization and dashboard design.

The dashboard provides a clear overview of sales performance and allows users to interact with the data through slicers and visual reports. Through this project, I strengthened my skills in Pivot Tables, Pivot Charts, KPI design, dashboard development, data visualization, and business analysis using Excel.
